# corridor.py 仕様

- 役割: 疑似3Dの通路描画（床・天井・壁テクスチャのスキャンライン描画）。バトル演出やステージ切替に使用。
- 主な関数: `_draw_infinite_corridor`, `_draw_floor`, `_draw_ceiling`, `_draw_walls`（内部ユーティリティ含む）。
- 定数: FOVやスライス数、テクスチャタイル寸法などレンダリングパラメータを定義。
- テクスチャ: `assets/texture` の画像を読み込み、なければ生成（チェッカーやレンガなど）。
- 入力: `pygame.Surface`, カメラ位置、経過時間。
- 出力: 画面への描画のみ。
- 注意: 高速化のためキャッシュを使用。高さが足りない場合は厚み補正を行う。
